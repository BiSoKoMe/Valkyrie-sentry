# Standing benign corpus — domains Valkyrie must NEVER block.
#
# Tier 1.7 of docs/TEST_PLAN.md. This is the regression gate for the failure
# mode that has actually hurt this project twice: the world-banks ML false
# positive, and the query-burst class that sinkholed microsoft/paypal/bing/
# live/linkedin. A false positive here means DNS returns 0.0.0.0 and a real
# person's bank, government portal, or hospital site is dead.
#
# DESIGN NOTE — why this list is not just `popular_domains.POPULAR_DOMAINS`:
# those 157 are already short-circuited by the popular-domain floor, so
# asserting they are unblocked proves only that the floor exists. The value of
# this corpus is in the LONG TAIL — regional banks, ccTLD news, universities,
# non-Latin-script sites, government portals — which get no floor protection
# and must survive the real scanner, blocklist, behavioural and anomaly stages
# on their merits. Prefer adding long-tail domains over famous ones.
#
# Format: one hostname per line. `#` comments and blank lines ignored.
# Every entry must be a real, resolvable, legitimate site.
